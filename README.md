# e-bash — симулятор сноса

Браузерная 3D-игра: гусеничный кран, шар-баба на тросе и дома, которые держатся на честном слове.
Выбей опоры — остальное сделает гравитация.

**▶ Играть: https://emorozoff.github.io/e-bash/**

Ничего устанавливать не нужно — игра открывается в браузере (Chrome, Edge, Firefox, Safari 16.4+).
Нужен интернет: движки графики и физики загружаются с CDN.

## Объекты

Хрущёвка · Котельная · Недострой · Девятиэтажка · Пятёрочка · Ларьки · Гаражи · ТЦ «Горизонт» · Почта России · Склад OZON

## Управление

| Клавиши | Действие |
|---|---|
| A / D | поворот стрелы |
| W / S | стрела дальше / ближе |
| Q / E | трос вверх / вниз |
| Пробел | сбросить шар |
| ↑ ↓ ← → | ехать |
| Shift | быстрее |
| 1 / 2 | шар 12 или 24 т |
| T | замедлить время |
| X | рентген нагрузок |
| C | сменить камеру |
| R (держать) | начать заново |
| P | сохранить кадр |
| U | спрятать интерфейс |
| Esc | пауза и меню |

## Как устроено

Один файл `index.html`: графика — [three.js](https://threejs.org), физика — [Rapier](https://rapier.rs).
Здание собрано из блоков со связями между ними. Вес течёт по связям к земле, перегруженные опоры
ломаются — так получается прогрессирующее обрушение.

Названия магазинов и логотипы использованы в шутку и принадлежат их владельцам.
